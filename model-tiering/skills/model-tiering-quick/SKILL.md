# 快速定档

## 输出

回复第一行顶格写一个标记：`▸` + 档位名。不做中文翻译，不写理由。

**档位名以插件包内 `config/tiers.json` 的 `models.*.efforts` 为准**，不要编造。

## 选档表

| 任务性质 | 标记 |
|---|---|
| 闲聊、一句话问答、简单格式转换 | `▸low` |
| 要办事、要多步、要查要改、拿不准 | `▸high` |
| 不可逆（删/覆盖/部署/发布）、疑难攻坚 | `▸max` |

## 三条硬规则

1. 标记必须是模型真支持的档位名，写错会被拒。
2. 边界不清就往上一档走（宁可贵一点，别返工）。
3. 所有渠道都标，不因对话类型省略。

需要完整规则（升级护栏、每日上限、记账）时改用 `model-tiering`。
